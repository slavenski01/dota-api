# Иконки героев

Каталог проверен 18 октября 2026 года: **127 героев**, все ID и внутренние имена
совпали с [OpenDota dotaconstants](https://github.com/odota/dotaconstants/blob/master/build/heroes.json).
Основной источник списка — [официальный herolist Valve](https://www.dota2.com/datafeed/herolist?language=english).
Изображения — оригинальные PNG 32×32 (Muerta — 32×31) из
[Steam CDN Valve](https://cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/heroes/icons/antimage.png),
без перекодирования. Это миниатюры героев для карты, а не большие иллюстрации.

**Dota 2 и изображения героев © Valve Corporation. Все права защищены.**
Товарные знаки принадлежат Valve; лицензия исходного кода проекта не распространяется
на эти изображения. Проект не связан с Valve. Изображения используются для
идентификации героев в локальном просмотрщике матчей.

`../../lib/hero-catalog.json` хранит дату проверки, SHA-256 ответа каталога, ID,
английские имена, внутренние имена, URL происхождения каждого файла, размеры,
длину и полный SHA-256. Имена файлов включают хеш содержимого. `heroes.json`
генерируется тем же скриптом для списка фильтров истории. Компоненты разрешают ID
через `hero-catalog.ts`; неизвестный ID не получает изображение другого героя.

Обновление из корня репозитория (нужна сеть; дата — день фактической проверки):

```sh
node scripts/sync-hero-icons.mjs --update --date=2026-10-18
node scripts/sync-hero-icons.mjs --check
```

Скрипт проверяет уникальность ID, внутренних имён и содержимого иконок, формат,
размеры и декодирование всех пикселей. Новый каталог публикуется только после
успешного скачивания и проверки всех файлов. При обновлении старые неиспользуемые
иконки удаляются; просмотрите diff и изменение числа/ID героев перед коммитом.
`--check` работает без сети. При просмотре игры используются только `/heroes/…`
и локальная подложка `/maps/…`; загрузка и обновление каталога не происходят в браузере.
