# Профиль и история матчей

## Профиль (E03-T01)

`/profile` позволяет явно выбрать Dota account ID или SteamID64. `POST /api/profile`
принимает `{ "kind": "account" | "steam", "id": "строка" }`; `GET /api/profile`
возвращает `{ profile }`, включая null до первого выбора. SteamID64 разбирается
через BigInt: universe=1, type=1, instance=1. Нулевой и анонимный UINT32_MAX
не выбираются. В ответе ID остаются строками. Ник никогда не служит идентификатором.

Сохранённый выбор общий для локального сервиса, переживает перезапуск и не меняет
принадлежность ранее сохранённых участников. Ответ OpenDota проверяется по ID.
Отсутствие имени/профиля даёт unknown, fh_unavailable=true — limited; эти признаки
не доказывают отсутствие игр. Ошибка источника сохраняет предыдущий выбор.

Сервер обращается к фиксированному HTTPS origin OpenDota, ограничивает ответ 2 MiB
и запрос 15 секундами. Ошибки API, сети, JSON и 429 не превращаются в пустой профиль.
Retry-After возвращается клиенту. API не требует ключа. Аватар допускается только
по HTTPS с доменов Steam. Проверенный контракт источника: https://api.opendota.com/api
(13 октября 2026). Личные данные и реальные ответы не коммитятся.

Проверка: `npm run test:profiles` — отдельная временная PostgreSQL; синтетические
ответы источника проверяют точность, неверные ID, идентичность, смену профиля и сбои.
