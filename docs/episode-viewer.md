# Просмотр эпизода E07

Ссылка `/matches/:matchId/episodes/:episodeId?datasetId=…&accountId=…`
сохраняет точный набор и эпизод. `mode=decision|retrospective` и `time` сохраняются
в URL. Время можно менять ползунком, стрелками (одна игровая секунда), кнопками
и переходом к событию. Запросы отменяются при изменении времени; старое состояние
не показывается под новой перспективой или временем.

API `GET /api/datasets/:id/episodes/:episodeId/view` проверяет аккаунт, набор,
эпизод, допустимое окно и готовность проверки набора. Полный обзор возвращает
последнее наблюдение в прошлом с возрастом до 5 секунд; конфликтующие наблюдения
и пропуски не заполняются. Перспектива игрока не читает полные отрезки и не
возвращает события/факты ретроспективного отбора. Все текущие командные значения
пока unknown. Камера и точный туман войны не восстановлены.

## Ручная оценка E07-T03

`GET/POST /api/datasets/:id/episodes/:episodeId/reviews?accountId=…` читает и
добавляет оценки в неизменяемую историю `episode_reviews`. POST требует
`expectedVersion`, статус, пояснение, автора, источник и перспективу; для
подтверждённой ошибки обязательна выполнимая альтернатива. Время выставляет сервер.
Автор — введённая подпись пользователя локального однопользовательского сервиса,
не подтверждённая аутентификацией личность.

Расширения схемы 0.1.0: статус `unreviewed` позволяет отозвать прежнюю оценку
новой записью; источник `timeline` отделяет состояния/события от карты.
Новая оценка `map` разрешена для набора с пригодными позициями в окне эпизода,
только в полном обзоре. Сервер сохраняет `mapContext`: версию подложки, проекции
и SHA-256 изображения. Клиент не может подменить эти поля. Старые оценки без
этого дополнения читаются без изменений. Клиент Dota 2 доброволен.

Блокировка строки эпизода и проверка версии предотвращают потерю изменений двух
вкладок (409); повтор того же завершённого запроса идемпотентен. Автоматический
эпизод и результат анализа не изменяются. Оценка связана с точным datasetId и
episodeId; повторный разбор не переносит её на новую версию.

## Карта E07-T02

По согласованию от 13 октября используется **приблизительная подложка 7.40**.
Версия и ограничения постоянно видны рядом с картой. Источник, формула, четыре
контрольных ориентира и измеренные расхождения: [калибровка](map-calibration.md).
Это общая пространственная навигация, а не точное воспроизведение рельефа 7.41.

Нормализация `e07-positions-v1` / парсер `normalized-v2` сохраняет мировые
координаты. API строит проценты изображения только для этой проверенной версии,
с наблюдением позиции ровно во время состояния. Будущие/устаревшие поля,
конфликтующие снимки, пропуски и точки за границами не рисуются и не прижимаются
к краям. Промежуточные положения не интерполируются. В перспективе команды
по-прежнему нет текущих позиций: проверка геометрии не подтверждает видимость.

С E13 маркеры показывают локальные портреты и выбирают героя; панель показывает его координаты и время
наблюдения. Для перекрывающихся маркеров есть список героев под картой.
Умирающие/мёртвые герои сохраняют портрет с отдельным крестом; команды различаются
цветом и формой рамки. Иконки также показаны в списке; [каталог и проверки E13](hero-icons.md).
Карта, состояние и таймлайн используют один ответ API. При загрузке нового
времени или перспективы предыдущие маркеры убираются.

Старые наборы не меняются: для появления координат нужно запустить повторный
разбор на странице матча. Старые ссылки и оценки остаются доступны; оценки не
переносятся в новые эпизоды автоматически. При отсутствии изображения панель
сообщает об ошибке, а состояния остаются доступны отдельно.
