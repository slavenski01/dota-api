## Первая проверка в новой сессии

```sh
export DOCKER_CONTEXT=colima-dota-api
git status
node scripts/local.mjs status
curl --fail http://127.0.0.1:3002/api/ready
node scripts/sync-task-board.mjs --check
```

Откройте профиль, готовый матч, полный просмотр и сохранённую заметку. Если VM
остановлена, сначала `colima start dota-api --activate=false`. Если службы
остановлены — `node scripts/local.mjs up`. Для новой машины начните с
[README](../README.md), настройки окружения и восстановления копии.

Обновление: новая копия → pull → сборка/миграции → readiness → старый матч/заметка.
Откат при изменившейся схеме: восстановление предыдущей копии в новый проект.
Не запускайте одновременно две версии к одной БД/Storage во время backup.

## Известные ограничения релиза

Карта 7.40 приблизительная; командный обзор, cooldown/canUse, роли, границы боёв
и ряды золота/опыта/добиваний не подтверждены или отсутствуют. Обновления Dota
могут потребовать новой версии парсера и повторной приёмки. Доступность истории
и реплеев зависит от OpenDota/Valve; при недоступном файле нужен ручной импорт.
Один live-прогон не является нагрузочным тестом или гарантией будущей доступности.

Публичный доступ, несколько пользователей, расписания, текстовая оценка ошибок,
сравнения и видео не входят в принятый релиз. Следующего автоматически
запускаемого эпика нет: выбор нового объёма остаётся за пользователем.
