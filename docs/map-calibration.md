# Приблизительная карта 7.40

13 октября 2026 пользователь согласовал подложку 7.40 для просмотра имеющихся
реплеев, затем утвердил план подключения координат и проверки ориентиров.
Соответствие изображения точному патчу больше не является условием E07-T02.
Рисунок местности не подтверждает проходимость, дистанции до нарисованных
объектов или доступный игроку обзор.

Подложка: `apps/web/public/maps/dota-7.40.webp`, 900 × 900, закреплённый
[OpenDota commit](https://github.com/odota/web/tree/7ccb42bd73bba450d3768ddf38aabc0e6ad9cb0c).
Источник и уведомление о лицензии сохранены рядом с изображением.

## Преобразование

Позиция мира: `cell * 128 + offset - 16384`, отдельно для X/Y/Z.
Сетевые поля: `CBodyComponent.m_cellX/Y/Z`, `m_vecX/Y/Z`.
Для сущности с родителем координаты нельзя объявлять мировыми без преобразования
родителя; такие наблюдения остаются неизвестными. Z не влияет на 2D-проекцию.
Версия патча в позиции остаётся неизвестной, а версия подложки хранится отдельно.

Проекция `opendota-740-v1` воспроизводит
[gameCoordToUV](https://github.com/odota/web/blob/7ccb42bd73bba450d3768ddf38aabc0e6ad9cb0c/src/utility.tsx)
и [VisionMap](https://github.com/odota/web/blob/7ccb42bd73bba450d3768ddf38aabc0e6ad9cb0c/src/components/Match/Vision/VisionMap.tsx):
`u = (x + 8192) / 16256`, `v = (8064 - y) / 16256`.
Ось X направлена вправо, Y — вверх; изображение начинается сверху слева.
Неравные по знаку границы воспроизводят исходные 127 клеток, а не округляются
до предположительных ±8192. Точки за пределами изображения не прижимаются к краям.

## Проверка на реплее

Неподвижные сущности прочитаны Clarity из контрольного R1 (тот же набор E01).
Фонтаны (-7456, -6938), (7408, 6848), древние (-5920, -5352), (5528, 5000)
совпадают после сдвига начала координат с независимо опубликованным
[справочником](https://github.com/whanyu1212/gem-dota/blob/dd20ca22df9f56e6b7ffb2b78359e6c13c314860/src/gem/data/map_constants.json)
и [контрольными ориентирами другого реплея](https://github.com/whanyu1212/gem-dota/blob/dd20ca22df9f56e6b7ffb2b78359e6c13c314860/tests/test_map_projection.py).
Это подтверждает трактовку координат; совпадение размеров разных карт из этого
не следует. Метаданные OpenDota относят контрольные реплеи к 7.41.

На изображении 900 × 900 вручную отмечены центры значков четырёх ориентиров.
Пиксельные отметки приблизительны (порядка 5 px), это не точный эталон рельефа:

| Ориентир | X мира | Y мира | Отметка на 7.40, px |
| --- | ---: | ---: | --- |
| Северо-западные врата | -6457.6875 | 7599.03125 | 55, 30 |
| Юго-восточные врата | 6425.53125 | -7313.78125 | 842, 869 |
| Нижний аванпост | -4096 | -448 | 210, 503 |
| Верхний аванпост | 3392 | -448 | 680, 405 |

Расхождение проверяется тестом проекции; максимально около 80 px (9% ширины).
Глобальный масштаб не подгоняется под перемещённые между патчами объекты.
Приблизительное наложение пригодно для общей навигации по эпизоду, но не для
вывода о точном расположении героя относительно нарисованного дерева или уступа.
Эта оценка относится только к четырём ориентирам, а не задаёт верхнюю границу
ошибки для всей карты.

## Результат реализации

Парсер `normalized-v2/clarity-5.0.1/protobuf-7.1`, нормализация
`e07-positions-v1`; старые наборы не переписываются. `WorldPositionTest`
сверяет четыре ориентира и отказы при отсутствующих полях/родителе;
`episode-view.test.mjs` — направление осей, границы и измеренные расхождения.
`node scripts/validate-states.mjs` повторяет сверку пяти локальных реплеев:
58230 известных позиций, 2190 совпавших компонент X/Y/Z на контрольных ticks.
Это отдельная проверка регрессий извлечения, а не уточнение точности подложки.

Проекция применяется только в полном обзоре и при пригодном наблюдении.
Сохранённая ручная оценка по карте содержит версию подложки, проекции и SHA-256
изображения. Ни карта, ни ручная оценка не подменяют неизвестный командный обзор.
