# Приёмка локального MVP — E10-T02

Дата: 13 октября 2026 года. Итог: **PASS** для согласованного MVP самостоятельного
изучения игры. Проверен реальный путь OpenDota → Valve CDN → Clarity → просмотр
матча → заметка → перезапуск → backup/restore. AI-тренер E08, сравнения E09 и
видео E11 не включены. Передача проекта оформляется в E10-T03.

## Окружение и воспроизводимость

macOS 26.5.1, Apple Silicon; Colima 0.10.3, VM Linux arm64, 4 CPU / 8 GiB RAM.
Docker CLI 29.9.0 / Engine 29.5.2, Compose 5.6.0, Buildx 0.38.0. Runtime: Node 26.3.0,
Next.js 16.4.0, Temurin JRE 21.0.12.1, PostgreSQL 18.6. Сборка: npm 11.16.0,
Kotlin 2.4.20, Gradle 9.5.1, Clarity 5.0.1 / protobuf 7.1. Контракт 0.1.0,
transport 1.0.0; parser `normalized-v2/clarity-5.0.1`, normalization
`e07-positions-v1`, rules `e06-v1`; модель LLM — null.

Реальный контрольный файл — первый образец локального E01 manifest. Его ID,
участник, заметка, хеш и адрес набора записаны только в
`data/acceptance/e10/result.json`, журнал — `worker.log` рядом. Копия с manifest
находится в подкаталоге `backup-*`; всё исключено из Git. Исходные live-ответы
профиля/истории сохранены штатным приложением в PostgreSQL.

```sh
export DOCKER_CONTEXT=colima-dota-api # только для этого окружения Colima
node scripts/local.mjs up
node scripts/acceptance.mjs
```

Сценарий читает `.env` и приватный manifest E01; другой manifest можно задать
через `DOTA_ACCEPTANCE_MANIFEST`. Требуются доступ к реальному OpenDota/CDN,
контрольный матч в доступной истории и свободный порт 3001 для восстановления.
Это явная live-проверка с записью данных, остановкой сервисов и созданием копии,
не тест для каждого коммита. Она оставляет основной сервис и заметку доступными;
отдельный восстановленный проект остановлен, его volumes сохранены.

## Отказы и независимые проверки

В дополнение к live-сценарию успешно выполнены **39 автоматических проверок**:
history (6), replay-source (5), replay-import (4), explorer-web (1), coverage (6),
player-context (5), episodes (5), item-fight-rules (6), replay-web (1).
Каждая интеграционная группа использует отдельную временную PostgreSQL.

- 429 и Retry-After сохраняются; повтор до разрешённого времени не перезаписывает
  историю. Сетевой сбой и пустой успешный ответ различаются.
- Отсутствующая ссылка, подтверждённо недоступный файл и временная ошибка
  источника различаются. Статистика остаётся доступной; ручной импорт работает.
- HTML вместо реплея, обрезанные архивы, неверный формат, размер и участник
  отклоняются. Реальный локальный файл проходит Clarity и production HTTP.
- Неизвестное/частичное покрытие отключает зависимые выводы. Положительные
  наблюдения не превращаются в доказательство отсутствия событий.
- Синтетический матч без эпизодов открывается целиком: 10 героев, события,
  фильтры, заметки, изоляция наборов/перспектив, проверка неверных ссылок.
- Повторный разбор сохраняет старые заметки и ручные оценки отдельно от нового
  набора. Отмена, SIGKILL, fencing и очистка временных файлов дополнительно
  проверены 33 сценариями E10-T01, включая отдельный Compose backup/restore.

Исходные ответы для отказов контролируемые: искусственно не исчерпывался
лимит OpenDota и не портились рабочие реплеи. Результат live-пути получен с
реальными источниками; эти две группы доказательств различаются намеренно.

## Найденные проблемы окружения и ограничения

Docker Hub возвращал 403; проверена сборка через `mirror.gcr.io/library`
с теми же закреплёнными digest. DNS контейнера возвращал EAI_AGAIN для OpenDota;
в Compose добавлен явный исходящий `DOTA_HTTP_PROXY` и `NODE_USE_ENV_PROXY`.
После подключения имеющегося локального прокси live-путь прошёл. На macOS
порт 3000 занят старым Node-процессом; новый сервис использует 3002. Старый
процесс не остановлен. Настройки и диагностика — в [local-operations.md](local-operations.md).

Карта 7.40 приблизительная; её нельзя применять для точной проверки рельефа
и проходимости. Командная видимость, cooldown/canUse, границы боёв и роли
не подтверждены. Нет временных рядов золота, опыта и добиваний; доступны HP/мана
и итоговая статистика. Патч конкретного матча может быть неизвестен. Произвольные
будущие версии реплеев не считаются поддержанными без отдельной проверки.
После истечения хранения у источника нужен сохранённый `.dem` или ручной импорт.
Публичное размещение, несколько пользователей, расписания и AI-тренер не
проверялись и не входят в релиз. Итоговая передача и чек-лист — E10-T03.
