# AI-тренер: Codex по подписке

18 октября 2026 года. E08-T01 завершена; контекст, экран отчётов и контроль качества — следующие задачи.

Пользователь согласовал E08 и использование текущей подписки. Официальный
[неинтерактивный режим](https://learn.chatgpt.com/docs/non-interactive-mode)
использует сохранённый вход; [авторизация ChatGPT](https://learn.chatgpt.com/docs/auth)
предоставляет доступ по подписке. Первый тест завершился через установленный
Codex CLI 0.162.0-alpha.17.2 и gpt-6-astra. API-ключ не используется, fallback
на отдельный платный API отсутствует. Разбор расходует общий лимит подписки.

## Запуск

На хосте нужны Node и Codex CLI с `codex login status` → ChatGPT.
После сборки пакетов выполните `npm run coach:bridge` в отдельном терминале.
Оставьте процесс работающим во время разбора. `DOTA_CODEX_BIN` позволяет указать
путь к установленному CLI. `.env.example` содержит настройки модели и лимитов.
Docker worker получает только каталог `data/coach-bridge`; авторизация Codex
остаётся на хосте. Ручной запуск моста не открывает сетевой порт.

## Исполнение и границы

Очередь pg-boss и `dota.coach_runs` атомарно сохраняют запрос, версию, контекст,
модель, снимок четырёх файлов методики и SHA-256. Повторный ключ запроса возвращает
тот же запуск; активный разбор игрока не дублируется. Неизменяемые входы и готовые
результаты защищены триггером БД. Потеря владения очередью запрещает публикацию.

Worker создаёт request-файл, host bridge эксклюзивно фиксирует claim и запускает
Codex с read-only sandbox, без пользовательского config, shell, приложений,
плагинов, hooks, web search и субагентов. Временный каталог содержит только схему
и фиксированные инструкции. Процесс ограничен watchdog по времени, памяти и
выводу. JSONL принимается только с успешным завершением и валидным usage.

Spool сохраняет результат для восстановления worker без повторного вызова.
Если bridge погиб после claim, неизвестный исход даёт `coach_interrupted`;
пользователь может явно запустить новую версию. Самостоятельного повторного
расходования подписки нет. Файлы spool содержат частные данные, исключены из Git
и не являются архивом отчётов: окончательные снимки хранятся в PostgreSQL.

По умолчанию gpt-6-astra/medium, один вызов на запуск, 180 секунд, 128 KiB prompt,
48 KiB JSON результата, 10 запусков за сутки UTC и 100 всего. Неуспешные запросы
тоже занимают квоту. Ограничения запусков меняются серверными переменными.
Размеры и таймаут не являются жёстким лимитом биллинговых токенов провайдера.
Токены и длительность сохраняются, стоимость в долларах — null, не ноль.
Остаток лимитов подписки локально не вычисляется; отказ провайдера показывается
без бесконечных повторов. Готовность модели подтверждается успешным вызовом,
а не наличием имени в каталоге.

## Проверки T01

`npm run build:packages`, `npm run typecheck`, `npm run test:coach-provider`.
Проверены конкурирующие запросы, права выбранного участника, квота, сохранение
usage и снимков, неизменяемость результата, отказ провайдера, повторное чтение
spool, неизвестный исход после смерти процесса и таймаут. Реальный smoke через
подписку: 10,97 с, 5468 input / 15 output tokens. Содержимое отчёта проверяет T02.
