# Проверенные наблюдения с датами

Наблюдения относятся к ограниченному набору запросов в исходной сессии. Они помогают выбрать источник и распознать ограничения, но не гарантируют поведение API в будущем. Личный профиль, ID контрольных матчей и секреты намеренно не сохранены: навык параметризуется текущим запросом.

## 9 октября 2026 года

- GetHeroes v1 без ключа ответил HTTP 403, а с предоставленным ключом — HTTP 200 и список героев. В этой проверке успешная авторизация подтверждалась сравнением двух запросов, а не одним статусом общедоступного метода.
- GetMatchHistory v1 вернул публичную историю, сначала один, затем пять матчей. Это подтвердило доступ к данной выдаче; не к любой приватной истории.
- GetMatchDetails v1 вернул HTTP 500 для трёх различных публичных матчей; для первого ошибка повторилась. Успешная выдача истории при этом сохранялась.
- Официальный GetSupportedAPIList с ключом перечислил GetMatchDetails и GetMatchHistory версии 1. Наличие метода в списке не подтвердило успешную выдачу деталей.

Следствие для аналитики: сбой одного метода не означает, что весь источник недоступен или ключ неверен. До получения сводки конкретного матча не делать выводы по его статистике.

## 12 октября 2026 года

- GetPlayerSummaries v2 вернул выбранный профиль. GetMatchHistory v1 с его Dota account_id вернул три последних матча; участник был найден в каждом.
- GetMatchDetails v1 вернул HTTP 500 для двух последних матчей этого профиля.
- GetMatchHistoryBySequenceNum v1 с номером последовательности из истории и запросом одной записи ответил HTTP 200, статусом 1 и нужным матчем. Совпадение match_id и account_id участника проверено отдельно.
- В полученной сводке были длительность, результат, герой, K/D/A, добивания, денаи, GPM, XPM, урон героям и строениям, лечение и уровень.

Следствие: базовая персональная статистика была доступна через альтернативный официальный метод. Эта проверка не подтверждала доступность таймкодов смертей, состояния способностей, покупок или подробных боёв.

## Что осталось непроверенным

- Доступность результатов OpenDota для этих контрольных матчей и полнота событийных журналов.
- Возможность получить реплеи этих матчей позднее.
- Полнота всей исторической выдачи и возможность восстановления скрытых игр.
- Автоматическое определение позиции и точного MMR.
- Причина HTTP 500: по полученным ответам она не установлена.

Не превращать эти неизвестные в утверждения об отсутствии данных у всех провайдеров. При новой проверке фиксировать дату, источник, тип матча и реально подтверждённые возможности без секретов.

## Основание методики и уточнение области

[Спецификация от 9 октября 2026 года](https://chatgpt.com/space/page_c843d6b0efac81919605cf6219f41bd9) содержит исходные правила D01, D02, L01, I01, F01, уровни данных и формат отчёта. В текущем навыке сохранены аналитические положения локально, поэтому доступ к Page для работы не обязателен.

По последующему согласованию навык отвечает за источники, необходимые данные, интерпретацию, сравнения и отчёт. Профиль, роль, MMR и герой не фиксируются. Авторизация, загрузчики, хранение, стек и интерфейс относятся к отдельной технической работе. Пользователь отдельно запросил размещение только в проекте.
